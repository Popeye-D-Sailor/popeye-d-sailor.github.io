🖥️ Live Avionics Web Cockpit & 3-Step Provider Onboarding Wizard

Captured directly from a live OpenWrt® router running the WGOPilot™ Web Cockpit and LuCI RPC backend.

1. Guided 3-Step Provider, Key & First-Flight Setup Wizard (#/setup)

Walks home and prosumer users through commercial VPN provider selection (NordVPN®, Surfshark®, Proton VPN®, Private Internet Access® / PIA®, Mullvad®, or Custom .conf/.ovpn), automated token/key registration in the AES-256 Hardware Vault, and first-flight leak verification—plus direct signup links for users who need a subscription.

2. Main Flight Deck & 4-Card Avionics HUD (#/cockpit)

At-a-glance status bar displaying live tunnel protocol (Outbound WireGuard® / OpenVPN® & Inbound Home VPN Server), active city/country gateway, Cabin Seal (Kill Switch) state, Autopilot watchdog status, and 1-click Flight Mode Presets (Standard, Gaming, Streaming, Max Privacy).

3. Flight Wizards Hub & 9 1-Click Task Assistants (#/quick-setup)

Task-driven wizards for Streaming & Smart-TV Unlock, Low-Jitter Gaming Optimization, Hotel & Airport Captive Portal Login Assist, Phone-Home Server setup, Strict Privacy Audit, and Encrypted Disaster-Recovery Backup Capsules.

4. 5-Section Avionics Settings & Real-Time Input Border Key (#/settings)

Fine-grained control over Tunnel MTU & TCP MSS Clamping, DNS-over-HTTPS / Private VPN DNS resolvers, IPv6 leak policy, USB tethering uplinks, and hardware LED bindings—with instant color-coded control borders (Recommended, Custom Value, Unsaved).

🛡️ Core Engineering & Security Architecture

Built in POSIX /bin/sh, OpenWrt® ucode (rpcd), and zero-build ES6 JavaScript to run smoothly on everything from 64MB travel routers to multi-gigabit ARM64/x86_64 gateways.

🔒 Fail-Closed Cabin Seal (fw4 & fw3 Kill Switch)

Atomic kernel-level firewall rules for both modern fw4 (nftables) and legacy fw3 (iptables) that prevent LAN-to-WAN traffic leaks during tunnel handshakes, key rotation, or upstream ISP dropouts.

🤖 Autonomous Autopilot & Warm Standby

Continuous latency and packet-loss telemetry with automatic failover to pre-staged Warm Standby endpoints and optional 1-click Censorship Shield (OpenVPN® TCP :443 Stealth fallback).

🔀 Policy-Based Split-Tunneling (Table 100)

Route specific LAN devices (Smart TVs, work laptops, gaming consoles) or domain/application presets through the VPN tunnel, direct ISP WAN, or scheduled bedtime rules without weakening leak protection.

🔐 AES-256 Hardware-Bound Cryptographic Vault

Encrypts all WireGuard® private keys, OpenVPN® credentials, and commercial provider API tokens at rest using hardware-derived entropy in /etc/wgopilot/vault/.

📟 42-Column SSH CLI & Mobile Termux Parity

Every capability in the Web Cockpit is also available over SSH inside a strict 42-column terminal interface designed for narrow smartphone SSH screens and headless administration.

🌍 19-Language Native Localization

Complete UI, interactive help cards, and documentation localization across 19 languages, including full RTL layout support for Arabic, Persian, Hebrew, and Urdu.
